# Installation Guide

## 1. Prerequisites

The platform requires:

- Linux server
- Docker
- Ollama
- Sufficient system RAM
- Network connectivity
- Open WebUI
- Qwen model
- Docker persistent storage

The exact hardware requirements depend on the selected model.
