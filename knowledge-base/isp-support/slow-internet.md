# Slow Internet

## Problem

Customer reports that Internet speed is significantly lower
than the expected service bandwidth.

## Initial Checks

Check:

- Customer package/profile
- Account status
- ONU status
- Router status
- Ethernet/Wi-Fi connection
- Number of connected devices
- Background downloads
- Speed-test methodology

## Diagnostic Procedure

### Step 1 — Check physical connection

Verify that the customer device and router are connected correctly.

### Step 2 — Check Wi-Fi

Determine whether the problem occurs:

- Only over Wi-Fi
- Only on one device
- On multiple devices
- Over wired Ethernet

### Step 3 — Check latency

Use a controlled ping test.

### Step 4 — Check packet loss

Repeated packet loss may indicate:

- Wireless interference
- Cable problems
- Congestion
- Upstream network problems
- Routing problems

### Step 5 — Compare wired and wireless performance

A wired test should be preferred when investigating
the actual Internet service bandwidth.

## Possible Causes

- Wi-Fi interference
- Weak Wi-Fi signal
- Faulty Ethernet cable
- Router limitation
- Multiple active users
- Customer device limitation
- Network congestion
- Upstream network issue

## Escalation

Escalate when the problem remains after customer-side
and access-layer checks.
